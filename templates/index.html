Early Stage Neurological Disorder Detection

Developed an intelligent Brain Computer Interface (BCI) application capable of detecting neurological disorders using EEG signal processing and Machine Learning, achieving high prediction accuracy.

Python Machine Learning TensorFlow Firebase
92%Model Accuracy

Problem

Early-stage neurological disorders are hard to detect without expensive, specialist equipment and long diagnostic queues, delaying treatment when early intervention matters most.

Solution

Built a BCI pipeline that processes EEG signals and classifies early markers of neurological disorders using a trained Machine Learning model, giving a fast, low-cost screening signal.

My Contribution

Designed the signal-processing pipeline, trained and tuned the ML model, and built the application layer end-to-end. This project received the Best Major Project Award from KSCST.
